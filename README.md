# XScalper Bot 🤖

Autonomous AI Scalper for XAU/USD — a trading dashboard and demo scalping engine.

## 🚀 Features

- XAU/USD trading dashboard
- Demo trading engine
- Risk management
- Maximum loss control
- Profit target
- Win-rate tracking
- Trade history
- Real-time demo price simulation
- Responsive mobile-friendly interface

## 📊 Demo Account

Starting demo balance:

$10,000

The demo mode uses simulated trades and does not connect to a real broker.

## ⚠️ Risk Warning

This project is for educational and demonstration purposes.

It does NOT guarantee profits and should not be used with real money without proper testing, risk management, and broker integration.
